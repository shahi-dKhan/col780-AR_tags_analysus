# Report Compilation Instructions

## Quick Start

To compile the report with bibliography, simply run:

```bash
./compile.sh
```

This will automatically run the full compilation sequence.

## Manual Compilation

If you need to compile manually or understand the process:

1. **First LaTeX compilation** (generates `.aux` and `.bcf` files):
   ```bash
   pdflatex main.tex
   ```

2. **Run biber** (processes bibliography from `tau.bib`):
   ```bash
   biber main
   ```

3. **Second LaTeX compilation** (includes bibliography):
   ```bash
   pdflatex main.tex
   ```

4. **Third LaTeX compilation** (resolves cross-references):
   ```bash
   pdflatex main.tex
   ```

## Why Multiple Compilations?

- **First pass**: LaTeX identifies all citations and writes them to `.bcf` file
- **Biber**: Reads `.bcf`, finds references in `tau.bib`, generates `.bbl` file
- **Second pass**: LaTeX reads `.bbl` and includes bibliography in document
- **Third pass**: LaTeX resolves all cross-references and page numbers

## Troubleshooting

### "Empty bibliography" or "No citations"
- Make sure you've run the full sequence: pdflatex → biber → pdflatex × 2
- Check that `tau.bib` exists in the same directory as `main.tex`
- Verify citations use `\cite{key}` with keys matching those in `tau.bib`

### "biber: command not found"
Install biber:
```bash
# macOS with Homebrew
brew install biber

# Or install full TeX Live distribution which includes biber
```

### Check for errors
```bash
# Bibliography processing log
cat main.blg

# LaTeX compilation log
cat main.log | grep -i error
```

## Files Generated

- `main.pdf` - Final output document
- `main.aux` - Auxiliary file with citations and references
- `main.bcf` - Biber control file (citations list)
- `main.bbl` - Bibliography data (generated by biber)
- `main.blg` - Biber log file
- `main.log` - LaTeX compilation log
